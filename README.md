# elawaady-db.com — Ahmed Elawaady

البورتفوليو الشخصي لأحمد العوضي. موقع ثابت بالكامل (HTML / CSS / JavaScript) — مفيش build ولا سيرفر ولا قاعدة بيانات.

## الملفات

```
index.html          الصفحة + مكتبة الأيقونات (SVG sprite) جوّه الملف
content.js          ← النصوص والأرقام الأساسية
script.js           منطق الموقع: العرض، البحث، اللغة، الوضع النهاري
style.css           الهوية البصرية كلها
app.html            التطبيق: الحسابات، التقييمات، ولوحة التحكم (#/admin)
admin.html          تحويلة للوحة الجديدة — مفيهاش أي منطق
firebase-config.js  إعداد Firebase (قيم عامة بالتصميم)
cloudinary-config.js إعداد رفع صور الإثبات
firestore.rules     مين يقدر يقرا ويكتب — دي الحماية الحقيقية
assets/             الشعار والصورة الشخصية والخطوط
CNAME               الدومين
```

## لوحة التحكم

**لوحة واحدة بس**، جوّه التطبيق: `app.html#/admin` — أو
`elawaady-db.com/app.html#/admin`.

بتفتح لصاحب الموقع بس. مفيش كلمة سر في المتصفح ومفيش صفحة إدارة منفصلة:
الصلاحية متربوطة بمعرّف حساب ثابت مكتوب جوّه `firestore.rules`، فحتى لو حد
شال الجافاسكريبت أو نادى الـAPI بإيده، السيرفر بيرفض. `admin.html` القديمة
بقت تحويلة للمسار ده وبس.

### أقسام اللوحة

| القسم | بيعمل إيه |
|---|---|
| **مراجعة التقييمات** | كل تقييم بكل بياناته — الاسم، الإيميل، النجوم، العنوان، النص، نوع التعامل، صور الإثبات، تاريخ الإرسال، الحالة — وأزرار: اعتماد · رفض · إخفاء · تثبيت · حذف |
| **المستخدمين** | الحسابات المسجّلة، إيقاف وتفعيل، وحذف الحساب وتقييماته |
| **الروابط** | إضافة وتعديل وترتيب وإخفاء روابط القنوات والمجتمعات |
| **محتوى البورتفوليو** | نصوص الصفحة الرئيسية — بتتحفظ في Firestore وبتبان على طول |
| **صور الموقع** | صورتك الشخصية وشريط الصور وصورة «تعاملات سابقة» واللوجو — بترفعها من هنا في أي وقت |
| **إعدادات الموقع** | بيانات التواصل، وقفل/فتح استقبال التقييمات |

### دورة حياة التقييم

المستخدم بيكتب تقييم → بيتولد **`pending`** إجباريًا (القاعدة بتفرض ده، مش
الواجهة) → بيوصلك في «مراجعة التقييمات» → **اعتماد** → يظهر للعامة في
«تعاملات سابقة». المرفوض والمخفي ما بيظهروش لحد غير صاحبه وغيرك.

صاحب التقييم مش بيقدر يغيّر `status` ولا `featured` ولا `moderatedBy` ولا
`moderatedAt` — ولا حتى إنت تقدر تعيد كتابة نص المستخدم أو نجومه. القواعد
بتحصر كل طرف في اللي يخصّه.

### النصوص اللي لسه في الملف

`content.js` هو الأساس، وقسم «محتوى البورتفوليو» بيعلو عليه. أي حقل تسيبه
فاضي بيرجّع النص الأصلي. الحاجات الأعمق — دراسة الحالة، مجالات الخبرة،
الرحلة — تعديلها من `content.js` مباشرة أوضح.

## التعديل من الملف مباشرة

لو مرتاح أكتر كده، افتح **`content.js`**. كل نص له نسخة عربي (`ar`) ونسخة إنجليزي (`en`):

```js
builds: [
  { icon:'i-chip',
    ar:['المنصات','الوصف بالعربي...'],
    en:['Platforms','Description in English...'] },
]
```

- **الأرقام** في `stats` — حطّ أرقامك الحقيقية. أي رقم تخليه `0` هيختفي من الصفحة.
- **دراسة الحالة** في `caseStudy` — دي أعمق من إنها تتعدّل من اللوحة، فتعديلها من هنا أوضح.
- **رقم الواتساب واللينكات** في `meta` — الموقع بيبني منها كل الأزرار والفوتر لوحده.

## الهوية البصرية

الألوان كلها متغيرات في أول `style.css`:

| | |
|---|---|
| Deep Petrol | `#071F29` |
| Turquoise (أساسي) | `#10B5BF` |
| Electric Cyan | `#20D6E3` |
| Soft Aqua | `#5DE7F2` |
| Orange (توقيع فقط) | `#FF8A1C` |

الأورانج مقصود يفضل نادر — خط رفيع، نقطة، زرار واحد، سنوات التايم لاين. الفيروزي هو اللون اللي الهوية تتعرف بيه.

فيه **وضع نهاري** كمان — الزرار بالشمس في الهيدر. ألوانه معرّفة تحت `:root[data-theme="light"]`.

## الخط والتطويل

الخط العربي **The Year of Handicrafts** في `assets/fonts/`. مفيهوش حروف لاتينية — أرقام بس — فالإنجليزي بيرجع تلقائيًا لـ **Manrope**. ده مقصود مش نقص.

علامة التطويل (**ـ**) بتتحط في كل كلمة عربية أوتوماتيك، مش مكتوبة في النصوص. الدالة في `script.js` بتحطها بعد حرف بيوصل باللي بعده وقبل الحرف الأخير. حروف زي **ا د ذ ر ز و ة ى** مبتوصلش باللي بعدها فالكلمة بتفضل زي ما هي، و **لا** متتلمسش عشان الليجاتشر.

للتحكم: `const KASHIDA = true;` في أول `script.js` — خليها `false` عشان تلغيه.

> التطويل على النص الظاهر بس. عنوان الصفحة ووصفها في `<head>` نضاف عشان البحث، ورسالة الواتساب بيتشال منها التطويل قبل الإرسال.

## بعد أي تعديل في CSS أو JS

غيّر رقم النسخة في `index.html` (`style.css?v=4` → `?v=5`) عشان تكسر كاش المتصفح عند الزوار. **تعديل `content.js` من اللوحة مش محتاج ده.**
