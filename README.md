# elawaady.com

بورتفوليو أحمد العوضي — موقع static ثنائي اللغة (عربي/إنجليزي).

يُنشر تلقائيًا عبر **GitHub Pages** من فرع `main` (الجذر) على الدومين `elawaady.com`.

## البنية

| الملف | الغرض |
|---|---|
| `index.html` | الصفحة كاملة + سبرايت الأيقونات SVG |
| `style.css` | التصميم — متغيرات الألوان في أول الملف |
| `script.js` | كل النصوص في `DATA` بأعلى الملف، نسخة `ar` ونسخة `en` لكل عنصر |
| `assets/` | الصور |
| `CNAME` | الدومين المربوط — لا تحذفه |

## التعديل

كل المحتوى (الخدمات، المشاريع، الدومينات، المهارات) في كائن `DATA` في أول `script.js`.
رقم الواتساب في ثابت `WHATSAPP` بأعلى نفس الملف.

بعد أي تعديل على `style.css` أو `script.js`، ارفع رقم النسخة في `index.html`
(`style.css?v=2`, `script.js?v=2`) لكسر كاش المتصفح عند الزوار.

أي push على `main` ينشر خلال دقيقة إلى دقيقتين.
